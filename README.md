# Festivals

Festivals 是一个节日美术提示词 Codex 插件。输入主题与元素要求，即可获得统一美术风格、可直接复制和编辑的中文提示词，用于全屏展示画面与配套入口按钮设计。

## 功能

- **全屏展示提示词**：根据主题、元素、布局和文案要求，整理完整的画面描述。
- **配套入口提示词**：依据已完成的大图或其实际内容描述，提取核心元素，编写延续造型、材质和配色的入口按钮提示词。
- **全中文输出**：提示词独立完整，方便复制到生图工具使用，也便于逐项编辑。
- **按需修改**：基于最新确认的提示词调整指定内容，保留已有约束。

插件只生成文字提示词，不直接生成或编辑图片。

## 美术风格

治愈系新中式立体卡通，融合圆润饱满的造型、细腻材质与电影级柔光，呈现精致、简洁的三维动画渲染观感。

固定的是造型、材质和渲染语言。主题、元素、时间、配色与氛围由输入决定，不套用固定的节日元素清单。详细需求以整理去重为主，简略需求补足必要的画面设计。

## 使用方式

1. 输入节日主题与所需元素，可同时指定布局、文案、尺寸和其他要求，获得中文全屏提示词。
2. 将提示词用于生图工具，完成大图。
3. 提供本次成图或对其实际元素、外观和配色的描述，获得配套入口按钮提示词。
4. 按需修改提示词，继续调整画面设计。

### 全屏展示示例

> 使用 Festivals 编写春节全屏展示提示词。元素只有三条红色绸带和一个金色圆环，米白色背景，主体靠右，左侧留空，不要文字。

### 配套入口示例

> 大图已经完成，实际画面是三条红色绸带环绕一个哑光金色圆环，没有文字。根据这些元素编写配套入口按钮提示词，要求透明背景。

### 修改示例

> 保留元素和布局，将整体氛围改为清晨暖光，提示词控制在 800 字以内。

没有指定的可选参数无需逐项填写。只有节日名称时，可以补充元素要求，或明确授权自由设计。

## 安装

1. 在 Codex 的“添加市场”中输入 `https://github.com/kira4094/Festivals`。
2. 选择 `festivals` 安装。
3. 在新对话中调用 Festivals，或使用 `festivals-prompts` 技能编写提示词。

仓库为私有仓库，安装时需要具有仓库读取权限的 Git 凭据。
