# Festivals 美术风格与配套输出原则

状态：已实现为仅交付中文提示词的本地技能。本文保存风格定义与内容边界；本阶段不导入图片或主动试出图，可依据用户提供的外部成图反馈改进文字规则。

## 已明确的边界

1. 插件保存可复用的美术风格，不内置节日元素清单、主题与元素的固定映射或默认故事。主题与内容需求来自本次外部输入。
2. 插件先交付全屏大图提示词。用户在外部完成大图后，提供本次成图或对其实际内容的描述，插件再编写入口小图提示词。小图沿用大图中被选元素的造型、材质、配色和光照语言，按按钮用途重新组织并简化。
3. 历史参考图仅用于提取美术风格。不得沿用其中的主体、人物、动物、服装、道具、动作、姿态、场景、背景、构图、布局、文字或故事。
4. 区分历史风格参考与本次生成的大图：前者仅提供风格，后者才是本次小图的元素与外观来源。两类参考的用途必须明确标注。
5. 插件只交付可直接使用、方便编辑的中文提示词，不导入图片、不管理图库、不调用生图工具。可读取用户为本次任务提供的图片，但不将其打包进插件。

## 共同风格定义

描述名：治愈系新中式柔光 3D 卡通。

固定“怎么画”，由用户决定“画什么，以及是什么氛围”。造型与渲染语言保持一致，不锁定时间、色温、具体配色或情绪；晨曦、月夜等差异本身不是风格偏离。

用户原始风格方向：治愈系新中式 3D 卡通、皮克斯 / C4D 渲染观感、柔和 PBR 材质、体积光、电影级柔光、极简干净、国际化。

这里的“皮克斯 / C4D”表达视觉目标，不代表实际使用这些制作工具。将其展开成可观察的特征如下：

| 维度 | 可复用特征 | 使用边界 |
| --- | --- | --- |
| 线条与形体 | 圆润饱满的三维体块，流畅清楚的外轮廓，柔化的转折，以体积与明暗塑形，整体轮廓简练 | 不继承参考主体的轮廓、比例或姿态；新主体按本次内容设计 |
| 笔触与媒介 | 精致三维动画与数字插画观感，连续平滑的明暗过渡，微观纹理细密，宏观表面整洁 | 绒毛、颗粒等属于材质细节，不将其误写成全局手绘笔触 |
| 材质 | 柔和的 PBR 外观，合理的粗糙度与柔润高光，材质间区分清楚；适当使用细微纹理、透光与散射表现 | 按外部指定物体选择适用材质，不为展示材质而添加物件 |
| 毛发条件 | 本次主体确有毛发时，表现密集柔软的细短毛束、层次和受光细节，保持蓬松感 | 不把所有物体绒毛化，不因参考图有动物而自动添加动物 |
| 配色 | 整体协调、主辅色关系明确，大色块干净，适量精致强调色；柔和冷暖对照与自然色阶 | 示例的暖金、奶油白、靛蓝等仅是本次历史画面的选择，不固定颜色、昼夜或光源物件 |
| 光影 | 电影级大面积柔光、细腻轮廓光、柔和接触阴影，亮部保留质感，暗部有层次，适度体积光与克制的辉光 | 光源方向、色温和环境随本次内容确定；不固定月光、夜景或发光主体 |
| 整体语言 | 治愈、亲和、精致、简洁的当代新中式 3D 卡通，具有易理解的国际化动画视觉表达 | 新中式气质通过设计与渲染语言体现，不自动增加传统器物、建筑、装饰或书法 |

“分层场景便于动画”属于画面组织目标，不是材质特征：需要时让元素边界与空间关系清楚，便于后续处理；单张图片不等于已经交付独立图层或动画资产。

## 大图到小图的流程边界

外部主题与内容输入 → 插件编写中文全屏提示词 → 用户在外部完成大图 → 用户提供成图或实际内容描述 → 插件提取适合按钮表达的核心元素 → 继承其造型、材质、配色与光照语言，编写中文入口提示词。

- 小图是本次大图的配套资产，不是历史参考图的换主题复刻，也不是两次互不关联的设计。
- 提取元素时不引入用户输入和本次大图均不存在的节日物件。
- 可以为小尺寸可读性简化细节与重新组织元素，但应保持被选元素的视觉身份。
- 未指定小图保留项时，可从本次大图的已有元素中选择核心组合；用户已指定时遵循用户要求。没有实际成图或其内容描述时，不以大图提示词冒充已生成结果。

## 历史提示词中不直接固化的内容

- 中秋主题及其中的所有具体元素、动作、位置、布局和文字，均只属于原案例。
- 小图提示词中的三张参考图数量、批注颜色含义和“保留第一版”等表述，是那次编辑过程的信息，不是插件的通用要求。
- “不含某种物件”的历史排除清单不成为通用禁用清单；后续外部输入可以明确要求这些内容。
- 大图的 16:9、2K，以及小图的方形 1536×1536、透明 PNG、至少 6% 边距等是已提供的案例规格，不属于风格定义。是否作为默认交付规格，仍待明确。
- 图层组织、动画拆分、导出格式、尺寸、透明度、文字和安全区，应在输出规范中另行确定，不混入通用风格段。
