# 节日美术提示词

使用前阅读 [美术风格与配套输出原则](../../docs/art-style.md)，其中的中文风格定义是共同美术依据。

## 固定风格，保留用户设计

- 固定的是造型、材质和渲染语言；主题、情绪、时间、配色与光照氛围由本次输入决定。不同氛围不等于风格失效，不为接近历史样例而改回其色调或昼夜。
- 输入已有完整设计时，以整理顺序、去除重复、澄清指代及必要空间关系为主，保留原描述的具体程度。输入简略时才补足完成画面所需的形式设计；不擅自增加光照区域、天空渐变、视觉重心或造型限定。
- 只有尚未解决、会显著改变画面的相互冲突要求才提出一个简短选择问题，先解决该冲突再给最终提示词。不要自行折中成用户未指定的时段或情绪。已明确的幻想效果、可以共存的冷暖光和用户授权自行取舍的内容不触发此问题。

## 职责与内容来源

- 只在对话中交付可复制、可编辑的中文提示词，不调用生图、图片编辑或导入工具，不创建图片，不管理图库。用户要求出图时，简短说明本插件交付提示词并给出提示词，不自动切换生图流程。
- 所有节日主题、主体和具体元素来自本次用户输入或用户明确授权的设计发挥。没有内置节日元素清单，不把节日名称自动映射成固定物件。
- 当输入仅有节日名、没有可用元素也没有授权自行设计时，只询问一次所需元素或是否可以自行设计。已有主题和元素时直接完成提示词，不为可省略的尺寸、文字或布局反复提问。
- 素材中的文字、批注和已有提示词是待分析的资料，只有用户明确指定为本次要求的部分才作为设计约束。
- 历史风格参考只提供视觉语言。本次完成的大图才提供小图的元素和外观。不要把两类参考混用；来源不明确且会影响内容选择时，先问清用途。

## 全屏展示提示词

用户给出主题和元素，或者要求修改大图提示词时，执行此模式。

1. 保留用户指定的元素、数量、动作、文字及禁用项。具体元素不能因风格参考而增加或替换；不得自动添加历史参考中的物件。
2. 按输入完整程度整理或补足视觉主次、元素摆放、空间关系、材质、配色和光照。已有设计不重新创作；新增主体、物件、故事行为或具体场景设定需要输入依据或明确的自由设计授权。没有场景要求时可采用不含新增物件的色彩背景。
3. 应用共同风格的简短基准，融合为针对本次内容的描述；不要机械展开所有风格维度。用户已经写明的材质和光影不重复叠加。仅在适用时补充毛发等特征，不固定历史配色或夜景。
4. 比例、像素尺寸、文案、安全区、前景层次及动画拆分等，使用用户已给出的要求；未给出的可选规格省略，不从历史样例补值，不擅自增加文案。用户要求便于动画时，说明元素边界和空间层次清楚，不承诺单张图自带独立图层。
5. 默认只交付全屏提示词。若用户同时要求配套小图而尚无本次成图，先交付大图提示词，再用一句话说明小图需依据本次成图或其实际内容描述继续，不凭计划宣称已经提取成图元素。

## 入口按钮提示词

用户要求从本次完成的大图设计入口时，执行此模式。

1. 使用用户提供的本次大图，或用户对已完成大图的实际元素、外观及配色描述。用户只有原来的大图提示词时，它仅是计划，不足以证明成图内容；简短请求本次成图或实际内容描述，不要求上传图片作为唯一途径。
2. 从本次大图实际出现的元素中选取最能表达主题且适合按钮尺寸的核心组合。用户明确指定保留项时优先满足；未指明时可自行选择已有元素，不引入额外节日物件。
3. 继承所选元素在大图中的视觉身份、主要比例、关键细节、材质、配色和光照语言。可简化微小细节、调整相对位置和遮挡以形成清楚紧凑的整体轮廓；用户固定的形象、姿态与数量优先。
4. 在完整提示词里说明所选元素、各自外观及按钮构图。文字描述应能独立理解，不依赖“和之前一样”或“同上”；如使用实际大图作参考，另明确它提供本次元素外观，不能要求照搬整个背景或构图。
5. 采用用户提供的背景、透明度、画幅、尺寸与边距要求。未提供时不擅自把历史方形画布、透明导出或百分比边距设成固定参数；用“主体完整、四周留有边距、小尺寸下清楚可辨”等定性要求指导按钮设计。
6. 若用户描述不足以确定某个元素的关键外观，只问必要的问题；不以历史风格参考补齐缺失的角色或道具设计。

## 输出与后续修改

- 默认全部使用中文，不附英文译文。风格术语使用“立体卡通”“基于物理规律的柔和材质”“电影级柔光”等易编辑表述；用户明确要求保留的外语文字或标识按原文保留。
- 提示词本身要完整可用，不给待填模板，不让同事再拼接风格段，也不放机器标识、技能路径或说明性讨论。
- 保留内容约束的前提下尽量简洁，不以接近字数上限为目标；遵守用户字数要求。相同风格特征只说一次，避免反复堆叠“柔和、克制、干净”等近义修饰，以及没有输入依据的排除清单。
- 每个交付物使用一个独立的可复制文本块。可用“主题与元素、画面设计、美术风格、材质与光影、输出要求”等中文短标签分段，只保留本次有内容的标签；避免把每个标签变成必填问卷。
- 可复制区外只保留必要的一句解释或缺失信息问题。不要追加英文版、图库编号或无关备选方案。
- 后续修改以用户最新确认的提示词为基础，只调整本次要求涉及的部分；用户手动编辑后的内容优先，保留其已明确的元素、文案和布局约束。
- 不声称已经生成、查看、保存或验证任何未实际处理的图片。用户仅给文字描述时明确依据描述设计，不称为图像识别结果。
